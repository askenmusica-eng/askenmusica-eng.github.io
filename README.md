# Portafolio de Max

Sitio de desarrollo web freelance (Concepción, Chile), publicado con GitHub Pages.

- `index.html`: portafolio
- `cafe.html`: landing de muestra para una cafetería
- `barberia.html`: sistema de reservas
- `gimnasio.html`: cobro de mensualidades
- `ferreteria.html`: informe de ventas
- `veterinaria.html`: formulario de ingreso por pasos
- `tienda.html`: tienda online con carrito
- `restaurante.html`: pedidos con vistas de garzón, cocina y caja
- `inventario.html`: inventario con alertas de stock

Todos los negocios son ficticios y usan datos de ejemplo.
